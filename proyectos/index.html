CV Responsive — Maquetació

Maqueté un CV web adaptable a partir de un diseño de Figma, con HTML semántico y estilos CSS separados del contenido.

  • HTML5
  • CSS3
  • Diseño responsive
  • Flexbox
  • CSS Grid
Ver código en GitHub
Detalles del proyecto

Objetivo

Trasladar el diseño de Figma a una página web y adaptar la composición a distintos tamaños de pantalla.

Desarrollo

Organicé el CV en secciones semánticas de presentación, experiencia y formación. Dejé el contenido en index.html y los estilos en style.css.

Tecnologías

Utilicé Flexbox para alinear elementos y CSS Grid para distribuir el contenido en columnas. Las consultas de medios ajustan la composición en tablet y escritorio.

Aprendizajes

Practiqué cómo traducir la jerarquía visual de una maqueta a HTML, separar contenido y presentación y reorganizar los bloques para que el CV se lea bien en pantallas estrechas.
