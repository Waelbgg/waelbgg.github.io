Ficha técnica del proyecto

Problema

La información académica está dispersa entre cursos. Consultar cada asignatura, priorizar tareas y centralizar fechas exige trabajo manual repetitivo.

Solución planteada

Apps Script actúa como intermediario: consulta cursos y tareas, prepara datos y los traslada a la base de datos «Tareas y entregas» de Notion. El objetivo es reducir la gestión manual durante DAW.

Consulta y diagnóstico trabajados

comprobarClassroom() y listarTareas(): comprobar acceso, consultar cursos y recuperar títulos, fechas e identificadores.

probarNotion(), diagnosticoNotion(), comprobarPropiedades(), pruebaGuardado() y guardarTokenNotion(): configuración, conexión, diagnóstico y pruebas de almacenamiento.

Sincronización y automatización previstas

sincronizarClassroomConNotion() centraliza la lógica prevista; instalarTriggerSincronizacion() prepara ejecuciones periódicas. Se plantea utilizar IDs únicos de Classroom para evitar duplicados y actualizar registros existentes.

APIs, configuración y datos

Classroom API para cursos y tareas; StudentSubmissions se contempla para estados de entrega. Notion API REST para consultas de diagnóstico y futura creación y actualización de registros. PropertiesService almacena configuración sensible y UrlFetchApp realiza comunicación HTTP. La estructura final de propiedades de Notion está pendiente de confirmar.

Estado y limitaciones

Consulta y listado de Classroom desarrollados y trabajados; diagnóstico desarrollado; configuración y base de datos de Notion preparadas. Se identificaron errores de autenticación y comunicación, incluido HTTP 401. La sincronización extremo a extremo no está validada; triggers y gestión avanzada se contemplan en la arquitectura.

Decisiones técnicas

Integración desacoplada, IDs externos, prevención de duplicados y actualización en lugar de creación repetida. Configuración sensible fuera de la lógica principal y funciones de diagnóstico para permisos, configuración y comunicación.

Aprendizajes y valor profesional

JavaScript aplicado a sistemas, automatización, consumo de APIs REST, autenticación por tokens, comunicación HTTP, gestión de errores, procesamiento de datos, bases de datos, arquitectura, documentación y Git. Experiencia práctica abordando una necesidad real mediante integración de plataformas.

    Roadmap de evolución
    1. Fase 1 · Consolidación

      Revisar código, permisos y scopes; validar Classroom, autenticación con Notion y estructura de base de datos.

    2. Fase 2 · Sincronización funcional

      Implementar y validar creación y actualización de registros, prevención de duplicados y gestión de errores de API.

    3. Fase 3 · Automatización

      Instalar triggers, definir frecuencia, mejorar logs y diagnósticos y controlar fallos.

    4. Fase 4 · Gestión avanzada

      StudentSubmissions y estados de entrega; gestionar cambios, tareas eliminadas o despublicadas y preservar propiedades editadas manualmente cuando corresponda.

    5. Fase 5 · Evolución

      Mejorar arquitectura, incorporar integraciones, crear interfaz de gestión y explorar una aplicación web más independiente de Apps Script.
